# Sanctrum Voice Landing Page

The official interactive web presence for **Sanctrum Voice** — the open-source Windows voice layer & companion.

→ Repository: [fadhiilahahmadzikri/sanctrum-voice-v2](https://github.com/fadhiilahahmadzikri/sanctrum-voice-v2)  
→ Live site: [sanctrum.app](https://sanctrum.app)

---

## ⚡ Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Styling:** Tailwind CSS v4
- **Animation & Physics:** GSAP (ScrollTrigger, Flip), Lenis Smooth Scroll, Motion (Framer Motion)
- **Audio & Visuals:** WebGL Shaders, Web Audio FFT DSP Spectrum, SVG Spherical Projection Math
- **Component Primitives:** Radix UI, Base UI, Lucide Icons, Simple Icons

---

## 🚀 Getting Started

```bash
# Install dependencies
pnpm install

# Run local development server
pnpm dev

# Typecheck and Lint
pnpm check-types
pnpm lint

# Production build
pnpm build
```
